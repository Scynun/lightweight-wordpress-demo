About this demo

A static demo for the Freelancer gig “Lightweight WordPress site at low cost” (ID 40806234). It shows the design and structure proposed for the client’s real WordPress site.

What’s included

Home (hero, video testimonial placeholder, services, portfolio, blog, enquiry form), Services, Portfolio with working category filter, Blog with 4 sample posts and filter, and a Contact page with enquiry form.

Lightweight by design

No frameworks, no web fonts, no external requests — the whole site is about 50 KB. Portfolio visuals are CSS gradients, not image files. Semantic HTML with meta descriptions and Open Graph tags on every page.

Placeholders

Video testimonial: no real client video was supplied — the home page shows a clearly-marked placeholder; the real video (YouTube embed or self-hosted MP4, lazy-loaded) would play there. Company name, clients and contact details are fictional (PixelRank Studio) — the client would supply their real brand, copy, photos and testimonial video. Enquiry form: validation + demo success message only; in WordPress it would submit via WPForms / Contact Form 7.

Real delivery would be WordPress

A lightweight theme matching this design, real WordPress pages (Home, Services, Portfolio custom post type, Blog, Contact), the client’s real video testimonial, WPForms enquiry form, Rank Math / Yoast SEO, caching + image optimization, and Analytics / Search Console setup.

No bid has been placed and no client has been contacted — this is a demo only.
